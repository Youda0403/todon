# 툿 상세의 직접 답글 개수

비교 기준: main `98b8d3469e694fd7431ef85c4952d028a6b414ec`.

툿 상세의 “답글 N개”가 타래의 모든 하위 글 수를 표시하던 것을 수정했다.
현재 선택한 툿을 `in_reply_to_id`로 가리키는 글만 센다.
답글 아래로 이어진 글과 이전 글은 개수에 포함하지 않으며, 타래 본문은 계속 표시한다.
답글 자체를 열면 그 답글에 직접 달린 글을 기준으로 센다.
새 답글을 작성한 뒤의 즉시 표시에도 같은 계산을 적용한다.

기존 코드에서 직접 답글 3개와 아래로 이어진 글 3개가 “답글 6개”로 표시되는 것을
재현했다. 수정 후에는 “답글 3개”로 표시하며, 타래의 글 6개는 모두 유지한다.

검증: `node --test tests/*.test.cjs` 77개 통과.
여러 단계의 답글, 답글 자체의 상세 화면, 작성 직후의 직접/하위 답글 개수,
삭제 뒤 재표시 및 기존 타래 갱신 동작을 검사했다.
