# 최근 3일 멘션의 목록 표시와 답장 확인 분리

비교 기준: main `3f085c2ed33d6c8f6a08e213105d4f418980e7ea`.

## 기록과 원인

2026-10-18.5 기록의 11:40 구간에서 요청 완료 시각과 소요 시간을 역산했다.

| 요청 | 소요 시간 | 시작~완료 (UTC) |
| --- | ---: | --- |
| 멘션 알림 | 3,994ms | 11:40:09.691~13.685 |
| 내 글 1페이지 | 2,129ms | 11:40:13.687~15.816 |
| 내 글 2페이지 | 1,946ms | 11:40:15.817~17.763 |
| 내 글 3페이지 | 3,295ms | 11:40:17.764~21.059 |

이전 구현은 각 멘션 페이지에 대해 `await loadMine(...)`을 마친 뒤 카드를 붙였다.
따라서 위 구간은 멘션 약 4초 뒤 답장 판별 약 7.4초까지 목록 표시를 보류하는 구조다.
멘션 진입 이벤트가 없는 기록이므로 터치부터 실제 표시까지의 전체 시간은 확정할 수 없다.
같이 실행된 툿 묶음 확인은 목록에서 기다리는 요청이 아니므로 위 시간에 더하지 않는다.
대부분 헤더 수신까지 걸린 시간이며, 기록만으로 서버 처리·네트워크·브라우저 대기를 구분할 수 없다.

같은 기록의 글 전송은 722ms, 두 툿 열기는 보관 본문 준비 2ms,
전체 타래 조회 506ms와 228ms였다. 이 값은 이번 기록에서 관측된 요청에 한정된다.

## 변경

- 멘션과 내 글의 첫 페이지를 동시에 요청한다. 아직 멘션을 받지 못했으면 내 글은
  한 페이지만 미리 읽고, 받은 멘션의 작성 시각에 맞춰 필요한 과거 기록을 이어 읽는다.
- 최근 72시간 멘션 자동 조회는 답장 기록을 기다리지 않는다. 각 페이지를 받으면 바로
  표시하며 최신·오래된 순, 전체·미답 필터 모두 같은 범위를 자동 조회한다.
- 확인하지 못한 항목은 `답장 여부 확인 중`으로 표시한다. 이미 답한 기록이나 수동 제외
  결정은 즉시 적용하고, 해당 글 작성 시각까지 내 글을 확인한 뒤에만 `아직 답 안 함`으로 판정한다.
  수신이 늦은 알림도 툿 작성 시각을 기준으로 확인한다.
- 미답 필터에서도 미확인 카드는 읽을 수 있다. 미확인 수를 따로 표시하고 미답 개수에 더하지 않는다.
  답한 글로 확인되면 필터에서 빠진다. 미확인 항목이 있는데 모두 답했다고 표시하지 않는다.
- 답장 기록 오류는 받은 멘션을 없애거나 3일치 알림 조회를 중단하지 않는다.
  별도 안내와 `답장 기록 다시 확인`으로 실패한 내 글 페이지부터 재시도한다.
- 화면을 떠나면 두 클라이언트 요청을 취소하고 늦은 응답을 무시한다. 돌아오면 받은 목록과
  확인 범위를 유지하며 중단 지점에서 이어간다. 새로고침은 다른 앱에서 새로 단 답글도 다시 확인한다.
- 상태가 같은 기존 카드의 DOM은 유지한다. 로컬 답장·수동 제외 기록은 그리기마다 한 번 읽어
  카드마다 반복해서 JSON을 파싱하지 않는다. 카드 갱신 시 읽던 위치를 보존한다.
- 삭제 알림 확인은 기존의 20개 단위 묶음 조회를 유지하며 화면 표시 뒤에 시작한다.
- 진단 버전 2026-10-18.6에 멘션 진입, 첫 카드 준비, 3일치 범위 완료, 답장 확인의
  시간·개수와 숫자 묶음 번호를 추가한다. 실제 픽셀 표시 시간은 아니다.
  툿 내용·주소·계정·토큰은 진단에 넣지 않는다.

다른 앱의 새 답글 확인, 빈 멘션의 불필요한 내 글 조회 방지를 검사한다.

이미 받은 목록을 그 결과 때문에 가리는 대기는 제거한다.
