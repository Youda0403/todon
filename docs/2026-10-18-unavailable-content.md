# 삭제·열람 불가 툿과 응답 없는 서버 처리

비교 기준: main `237a64a939257a26044cc23759447fb6babb38cf`.

## 안내와 제한 시간

일반 API 읽기는 15초, 쓰기는 60초, 파일 업로드는 120초로 제한한다.
기존 푸시 점검의 더 짧은 제한과 호출자의 취소 신호도 유지한다.
응답 본문을 받는 중 멈춘 경우도 제한 시간에 포함한다.

- 단일 툿 조회의 Mastodon JSON 404 또는 410:
  “이 툿은 삭제되었거나 지금 계정에서 볼 수 없어요.”
- 네트워크/DNS 실패: 인터넷 연결 또는 서버 운영 상태 확인 안내.
- 제한 시간 초과: 불러오기를 멈췄다는 안내와 재시도.
- 로그인 만료, 권한 부족, 요청 제한, 서버 오류, HTML 등 잘못된 응답도 구분한다.

타래의 삭제·열람 불가가 확인되면 오래된 본문을 지우고 재시도 및 알림 목록으로 돌아가는
버튼을 표시한다. 일시 오류로 새로고침만 실패했다면 본문을 유지하고 오류를 화면에 남긴다.
멘션 관리도 불러오기 실패를 빈 목록으로 표시하지 않고 안내와 재시도를 남긴다.
읽기 한쪽이 실패하면 함께 진행하던 타래 요청을 취소한다.

게시의 응답을 확인하지 못했을 때는 결과가 반영되지 않았다고 단정하지 않는다.
초안을 보존하고 같은 작성 창의 재시도에는 기존 Idempotency-Key를 유지한다.

## 이 앱의 알림 자동 정리

- 툿이 없는 알림과 이 계정에서 볼 수 없다고 확인한 툿의 알림을 제외한다.
- 알림 새로고침은 첫 페이지를 다시 맞춰, 서버에서 사라진 오래된 알림도 화면에서 뺀다.
- 4.3 이상 등 지원 서버에서는 알림 툿들을 묶음 조회한다. 화면 표시는 기다리지 않으며,
  계정별로 동시 요청을 합치고 같은 툿의 확인은 1분 간격으로 제한한다.
- 묶음 조회를 지원하지 않는 서버에는 알림마다 개별 요청을 보내지 않는다.
  서버 목록 갱신 및 해당 툿을 열었을 때의 응답으로 정리한다.
- 확인된 항목은 캐시된 전체 알림·멘션 관리·앱 내 팝업과 확인된 읽지 않은 개수에서 뺀다.
  계정을 전환한 뒤 도착한 결과가 다른 계정의 목록이나 숫자를 지우지 않게 구분한다.
- 숨김 기록은 계정별 툿 ID와 시각만 최근 500개 보관한다. 나중에 다시 열람되는 응답을
  받으면 숨김 기록을 해제한다.

Mastodon은 삭제와 비공개·접근 불가를 모두 404로 표시할 수 있다.
따라서 삭제로 확정했다고 표시하거나 서버의 알림을 영구 삭제하지 않는다.
HTML 404, 연결 오류, 시간 초과, 401·403·429·5xx로 알림을 숨기지 않는다.
원격 서버가 사라졌더라도 로그인한 서버에 복사본이 남아 있으면 그 복사본은 열 수 있다.

## 검증

```sh
node --test tests/*.test.cjs
```

53개 검사: 기존 알림 복구와 타래·진단 기록, 읽기/본문 수신 시간 초과, 취소,
HTTP 상태 구분, HTML 404 보호, 계정별 숨김과 복원, 묶음 확인 중복 제한과 미지원 서버,
초안과 재시도의 처리 등을 검사한다.

별도 Chromium 모바일 검사에서는 실제 화면의 삭제 안내, 알림 목록 복귀,
삭제·null 툿의 자동 정리, 목록과 읽지 않은 개수, 서버 오류·네트워크 실패·지연·HTML·권한 안내,
재시도, 캐시된 본문 유지 또는 제거, 묶음 API 미지원 서버, 멘션 오류 안내,
게시 응답 시간 초과 후 초안 보존과 Idempotency-Key 유지까지 확인했다.
삼성 브라우저 실기기와 실제 서버 장애는 직접 검증하지 못했다.
